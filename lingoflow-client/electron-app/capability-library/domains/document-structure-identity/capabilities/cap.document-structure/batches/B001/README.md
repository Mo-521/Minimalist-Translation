# B001 — Document Structure

This is the first D1 capability build and acceptance batch, not an algorithm version. Papers 1–10 (126 pages) supplied the primary regression and full-document review. Papers 11–12 (29 pages) supplied independent supplemental runs in the same batch.

The accepted multi-step Object-first implementation is maintained at the capability root. The batch outcome is `pilot_ready` with known semantic-boundary and pending-ownership limitations; it is not a claim of universal PDF coverage or authorization to replace the legacy translation path.

The application can invoke D1 independently. Translation, layout, masking, and PDF export still use their existing path. The B001 manifest and capability catalog retain sample identity and outcome metadata; this directory intentionally does not duplicate PDFs, stage output, full review drafts, or implementation code.
